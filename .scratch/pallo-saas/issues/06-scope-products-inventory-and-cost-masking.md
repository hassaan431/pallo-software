# Scope Products, Categories and Inventory with Cost Price Masking

Type: task
Status: closed
Assignee: Antigravity
Blocked by: none (04 resolved)

## Question

How do we update all inventory, product, category, brand, and stock adjustment endpoints in [app.py](file:///Users/hassaanjazz/Desktop/Projects/SaaS/Pallo/app.py) to scope records by `current_user.company_id`, while strictly redacting `cost_price` and profit margin data when accessed by non-admin roles (`salesman`, `warehouse_manager`) as mandated by ADR 0003?

## Resolution

1. **Catalog & Inventory Scoping**:
   - Scoped `/inventory`, `/inventory/download_csv`, `/inventory/add`, `/inventory/edit/<id>`, `/inventory/adjust_stock`, `/inventory/delete/<id>`, `/api/inventory_history/<id>`.
   - Scoped category management (`/categories`, `/categories/add`, `/categories/edit/<id>`, `/categories/delete/<id>`).
   - Scoped brand management (`/brands/list`, `/brands/add`, `/brands/edit/<id>`, `/brands/delete/<id>`, `/brands/search`).
   - Scoped product API endpoints (`/products/list`, `/products/search`).
   - Scoped catalog helper functions in `database.py` (`get_public_products`, `get_brochure_products`) with company_id filtering.
2. **ADR 0003 Commercial Cost Masking**:
   - Redacted `cost_price` (set to `None`) in `/products/list` and `/products/search` for non-admin users (`salesman`, `warehouse_manager`).
   - In `/inventory`, zeroed `total_stock_value` and stripped `cost_price` for non-admins.
   - In `templates/inventory.html`, hid Total Stock Value stat card, table cost/margin/stock value cells, modal cost inputs, and edit button `data-cost-price` attributes for non-admins.
   - In `/inventory/edit/<id>`, ensured non-admin edits preserve existing database `cost_price` to prevent accidental wiping or tampering.
   - In `/inventory/download_csv`, omitted `Cost Price`, `Stock Value`, and financial totals rows when generated by non-admin users.
3. **Database & Execution Adapter**:
   - Added `PooledCursorWrapper` to `database.py` to transparently adapt `?` to `%s` for PostgreSQL cursor operations.
   - Automated `company_id` columns and Company 1 backfill across all 18 multi-tenant tables in `_ensure_sqlite_companies_support()`.
4. **Verification**:
   - Added test suite `tests/test_product_scoping.py` (8 test cases covering isolation, search, mutations, cost masking, CSV redaction, cost preservation). All 44 tests pass cleanly.
